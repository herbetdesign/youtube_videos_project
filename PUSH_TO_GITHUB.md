# Publicar no GitHub

Este projeto já existe no repositório remoto `herbetdesign/youtube_videos_project`. Para atualizar sua cópia local, use:

```powershell
git clone https://github.com/herbetdesign/youtube_videos_project.git
cd youtube_videos_project
```

Para enviar futuras alterações:

```powershell
git add .
git commit -m "Describe your changes"
git push
```

Não coloque senhas ou tokens de acesso nos arquivos do projeto. Use a autenticação do GitHub configurada no computador.
